# Кредитный скоринг (Random Forest и Gradient Boosting)

## Задание
Необходимо разработать модель кредитного скоринга по существующей распределенной базе данных клиентов и их кредитных историй (scoring_case.csv), используя алгоритм случайного леса и градиентного бустинга. С помощью функции GridSearchCV найти оптимальные параметры для обоих методов. Сравнить и проанализировать точность получаемых моделей. Провести их интерпретацию. Сделать вывод относительно применимости того или иного алгоритма для анализируемого набора данных. Спрогнозировать вероятность класса 1 для недостающих данных в столбце TARGET. Прислать файл .ipynb и предсказанную 1000 значений по столбу TARGET.

## Данные
В файле scoring_case.csv (или scoring case.xlsx) содержится 6797 записей и 122 признака.
5797 строк размечены по целевой переменной TARGET (449 дефолтов, то есть около 7.8%).
У 1000 строк значение TARGET не заполнено, для них сделан прогноз.

## Ход работы
1. Проведен EDA: посмотрели распределение таргета, корреляции и уровень дефолта по категориям (образование, семейный статус, тип дохода).
2. Обработана аномалия в DAYS_EMPLOYED (значение 365243 дня вынесено в отдельный признак, само значение заменено на пропуск).
3. Добавлены новые признаки: возраст в годах, стаж, соотношение платежа к кредиту (PAYMENT_RATE), долговая нагрузка (ANNUITY_INCOME_RATIO) и среднее по внешним источникам (EXT_SOURCES_MEAN).
4. Удалены 17 колонок, где пропусков было больше 60%.
5. Собраны пайплайны с импутацией (медиана для чисел, мода для категорий) и OneHotEncoder.
6. Выборка разбита на train (80%) и holdout (20%) со стратификацией.
7. Через GridSearchCV на 5 фолдах по метрике ROC-AUC подобраны параметры для Random Forest и Gradient Boosting.
8. Сделана оценка на holdout выборке, из-за дисбаланса порог подобран по максимуму F1-score (~0.12).
9. Построены графики важности признаков (MDI и Permutation Importance), а также Partial Dependence Plots.
10. Сформирован файл с предсказаниями для 1000 клиентов.

## Результаты

| Модель | ROC-AUC (CV) | ROC-AUC (holdout) | F1 (порог 0.5) | F1 (опт. порог) |
| --- | --- | --- | --- | --- |
| Random Forest | 0.7475 | 0.6814 | 0.2308 | 0.2458 |
| Gradient Boosting | 0.7569 | 0.7056 | 0.0426 | 0.2745 |

Градиентный бустинг показал качество выше как на кросс-валидации, так и на тесте. При пороге 0.12 F1-score достигает 0.275, тогда как при обычном пороге 0.5 модель дефолты почти не ловит из-за дисбаланса классов.

Главные признаки по важности: EXT_SOURCES_MEAN, EXT_SOURCE_2, EXT_SOURCE_3, возраст (AGE_YEARS) и соотношение платежа к сумме кредита.
